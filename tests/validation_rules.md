# 整合性チェックルール

Notionデータの整合性を担保するためのルール定義。  
タグ整合性チェック時はこのファイルを参照すること。

---

## ルール一覧

### R-01: 業界カテゴリの許容値チェック
- **内容**: `業界` フィールドの値が `schema/taxonomy.md` の業界カテゴリ10種に含まれること
- **違反例**: `"自動車"` (正: `"自動車・モビリティ"`)、`"IT"` (正: `"テクノロジー・AI"`)
- **対応**: notion-update-page で正しい値に修正

### R-02: タグの許容値チェック
- **内容**: `タグ` フィールドの値が `schema/taxonomy.md` の39タグに含まれること
- **違反例**: `"テクノロジー・AI"` をタグに使用（業界カテゴリ名をタグに誤記入）
- **対応**: 許容値外のタグを削除 or taxonomy.mdに追加申請

### R-03: Factフィールドの非空チェック
- **内容**: 全記事の `Fact` フィールドが空でないこと
- **対応**: 空の場合はコンテンツから自動生成して補完

### R-04: 日付フォーマットチェック
- **内容**: `日付` フィールドが `YYYY-MM-DD` 形式であること
- **違反例**: `"2025/08/01"`、`"R7.8.1"`
- **対応**: notion-update-page で正しい形式に修正

### R-05: 業界・タグの設定状況チェック
- **内容**: 業界・タグが未設定の記事を検出する（警告レベル、エラーではない）
- **対応**: ユーザーに未設定記事一覧を提示し、補完を促す

### R-06: タグ数チェック（推奨）
- **内容**: 1記事あたりのタグ数が6個以上の場合は過多として警告
- **対応**: 主要タグ5個以内に絞ることを推奨

---

## チェック実行手順（手動）

```
「News DBのタグ・業界の整合性をチェックしてください」
```

Coworkが以下を実行：
1. notion-search で全記事を収集
2. 各ルールに照らして違反を検出
3. 違反一覧をレポート
4. 修正が必要な場合は確認後に notion-update-page で修正

---

## チェック実行手順（自動化・将来）

`scripts/validate_taxonomy.py` を実装後は以下で実行：

```bash
python3 scripts/validate_taxonomy.py
```

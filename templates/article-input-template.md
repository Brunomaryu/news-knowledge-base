# 記事入力テンプレート

Coworkに記事を追加依頼する際のフォーマット。  
このテンプレートをコピーして内容を記入し、Coworkに貼り付ける。

---

## テンプレート

```
## 記事追加依頼

### Fact（核心ファクト・1行）
[記事の一番重要な事実を1文で]

### 背景
[このニュースが起きた文脈・前提・業界の流れ]

### 示唆（コンサル視点）
[So What? 何が重要か、何が変わるか、どう見るか]

### 業界
[taxonomy.mdの業界カテゴリから1〜3個]

### タグ
[taxonomy.mdのタグから2〜5個]

### 日付
[YYYY-MM-DD]
```

---

## 記入例

```
## 記事追加依頼

### Fact（核心ファクト・1行）
トヨタが米国生産3車種（カムリ・ハイランダー・タンドラ）を日本へ逆輸入

### 背景
日米関税25%への対応として、米国工場生産車を日本市場向けに輸入するスキームを検討。
トヨタの北米生産体制（年間約160万台）の一部を日本市場向けに転換する異例の判断。

### 示唆（コンサル視点）
日米関税が自動車メーカーの生産配置ロジックを根本から変える可能性を示す事例。
「どこで作るか」よりも「どこに売るか」で生産地を決める逆転の発想が広がるか。
ティア1サプライヤーは国内生産向け受注減少リスクを織り込む必要あり。

### 業界
自動車・モビリティ, 政策・マクロ経済

### タグ
トヨタ, 規制, 海外展開, サプライチェーン

### 日付
2025-08-01
```

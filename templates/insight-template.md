# 示唆フィールド 推奨フォーマット

**バージョン:** v1.0（2026-06-28）

> **重要:** これは推奨フォーマット。短い速報・メモ段階の記事は自由記述で登録してよい。
> 質より量を優先する期間は簡易記述でOK。後から補完する。

---

## フルフォーマット（精読記事・重要記事向け）

```
【何が変化したか】
（市場・技術・規制・企業行動の具体的変化を1〜2行で。数字があれば入れる）

【なぜ重要か】
（なぜこれが業界・顧客・競合にとって重要なのか。So Whatを1〜2行で）

【誰へ影響するか】
（具体的なプレイヤー名・業界・ステークホルダー）

【波及先・連鎖効果】
（サプライチェーン上流/下流・隣接業界・競合他社への波及）

【コンサル活用】
（提案テーマ・分析軸・仮説設定・クライアントへの活用イメージ）

【Action】（任意）
（次に調べるべきこと・確認すべきこと・フォローアップ事項）

確度: ✅確実 / 🔶推測 / 💡仮説
```

---

## 簡易フォーマット（速報・メモ向け）

```
So What: （1行で本質を）
影響先: （プレイヤー名）
活用: （コンサル視点での使い途）
確度: ✅確実 / 🔶推測 / 💡仮説
```

---

## 確度フラグの使い方

| フラグ | 使用タイミング | 例 |
|---|---|---|
| ✅確実 | 公式発表・決算数値・法律など1次情報ベース | 「〇〇社が売上△%増と発表」 |
| 🔶推測 | 状況証拠・複数情報源からの推断 | 「このトレンドから〇〇が加速する可能性が高い」 |
| 💡仮説 | 個人的な仮説・着眼点・アイデア段階 | 「〇〇が起きれば△△という構造変化が来るかもしれない」 |

---

## 記載例

```
【何が変化したか】
NVIDIAのBlackwellアーキテクチャがH100比で推論性能4倍・メモリ帯域2倍を実現。2025年Q1から量産出荷開始。

【なぜ重要か】
AI推論コストの劇的低下により、これまでGPU代が障壁だった中規模企業のAI本格活用が現実的になる転換点。

【誰へ影響するか】
・AMD（追随が急務）
・クラウド3社（インスタンス刷新コストが発生）
・日本の製造業AIベンダー（顧客の導入機運が高まる）

【波及先・連鎖効果】
DRAM/HBM需給がさらにタイト化→SKハイニックス・マイクロンに追い風。
電力消費増大→データセンター電力問題が再燃。

【コンサル活用】
製造業クライアントへの「AI推論コスト試算」ベースの導入ROI分析に活用可能。
「いまGPUを買うか・待つか」の意思決定支援フレームとして使える。

【Action】
Blackwellの実価格・AWS/Azure/GCP提供タイミングを確認。

確度: ✅確実（NVIDIAの公式発表ベース）
```
